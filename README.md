# Ежедневник

Простой планировщик на неделю, работает прямо в браузере, без установки.

## Возможности

- **Неделя** — дела на каждый день с понедельника по воскресенье, разделённые на «Утро», «День» и «Вечер».
- Отметки **✓ сделано** и **✕ не сделано**, прогресс по дню и итоги недели.
- **Глобальные задачи** — крупные дела без привязки к дню.
- **Цели** — со сроком и шагами; процент выполнения считается автоматически.
- Перетаскивание (за значок ⠿) — меняйте порядок, переносите дела между днями и временем суток.
- Двойной клик по тексту — редактирование.
- Светлая и тёмная тема (по настройкам системы).

## Запуск

Откройте `index.html` в браузере. Данные сохраняются в `localStorage` этого браузера.
